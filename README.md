## ⭐ Projeto em Destaque

### 💰 Dashboard Financeiro Full Stack
🔗 **Deploy:** https://dashboard-finance-gray.vercel.app  
🔗 **Repositório:** https://github.com/BreninDevv/dashboard-finance

Aplicação full stack para **controle financeiro pessoal**, com autenticação e persistência de dados.

**Principais funcionalidades:**
- 🔐 Login e registro com JWT
- 💸 Controle de ganhos e gastos
- 📊 Gráficos interativos com Recharts
- 🧾 Histórico de transações
- 📝 Todo List e lista de desejos
- ⚖️ Cálculo automático de saldo

**Stack utilizada:**
- Frontend: Next.js + Tailwind CSS
- Backend: Node.js + Express
- Banco de dados: MongoDB Atlas
- Deploy: Vercel (frontend) e Render (backend)
- Arquitetura: Monorepo
